I cannot find the downloaded file

Open your browser’s Downloads list (Ctrl+J in most Windows browsers). Find the file named above and choose Show in folder. You can use the download button again to save another copy.

4. Turn on the connection

In WireGuard, select your imported configuration and click Activate. The website does not turn it on for you.
