XIANGEN HU · RESEARCH NETWORK

Your browser. One connection switch.

Install once. Sign in with your SKO account, connect automatically if your VPN access is approved, and use Disconnect from the extension toolbar. No WireGuard profile is needed.

Preview distribution: these packages are for manual installation and testing. Store listings and Firefox signing are not yet published. Your administrator must enable the HTTPS proxy server before Connect works.

Chrome, Microsoft Edge, Brave & Opera

One Chromium package supports these desktop browsers on Windows, macOS and Linux.

Download Chromium extension
Manual preview installation
  1. Download and extract the ZIP into a folder you will keep.
  2. Open your browser’s Extensions management page. Enable Developer mode.
  3. Select Load unpacked and choose the extracted folder containing manifest.json.
  4. Pin Research Network to the toolbar. Open it and click Sign in & connect.

Firefox

A separate Firefox package uses Firefox’s own proxy controls.

Download Firefox extension
Temporary preview installation
  1. Extract the ZIP.
  2. Open about:debugging#/runtime/this-firefox.
  3. Select Load Temporary Add-on and choose manifest.json from the extracted folder.
  4. Open Research Network and click Sign in & connect.

Temporary installation ends when Firefox restarts. Permanent installation needs Mozilla signing. WebRTC calls are disabled while this preview connection is on and restored when disconnected.

Sign in, then browse

  1. Open the extension and click Sign in & connect.
  2. Sign in on the account tab it opens. If you already have VPN access and accepted the research-use agreement, the browser connects automatically.
  3. Wait for Your browser connection is on, then browse normally. Use Disconnect in the extension when finished.

If your account is awaiting VPN approval, use the request-access instructions on the sign-in page. You do not need to copy a code or download a WireGuard file.

Safari, phones & tablets

This extension release targets the five desktop browsers above. Safari, Chrome on phones, and iPhone/iPad browsers are not covered by these packages. Use the portal’s WireGuard option on those devices. This release does not claim Android extension support.

Only this browser’s regular HTTP/HTTPS traffic uses the proxy. Private windows, other applications, non-web protocols and browser-internal traffic are outside its scope. An extension or administrator policy that already controls your proxy can prevent connection. If the proxy fails, web browsing stays blocked until you disconnect; the portal remains reachable for recovery.
